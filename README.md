# Urban Mobility & Smart Cities

AI-driven urban mobility and pedestrian safety demonstration.

## Project overview

This group project is a client-side demonstration of pedestrian route guidance and safety analysis. It includes a map interface, simulated crowd clusters, risk zones, risk-weighted route selection, and alerts.

## Features

- Leaflet and OpenStreetMap map integration, centered around M. Chinnaswamy Stadium.
- Simulated crowd clusters and dynamic risk zones.
- Risk-weighted graph routing using Dijkstra's algorithm.
- Voice and popup alerts, plus a drone-warning simulation.
- Demo controls for selecting start and destination points and running the simulation.

## Technologies

HTML, CSS, JavaScript, Leaflet, OpenStreetMap, Python, and GeoJSON.

- `data/exits.geojson`

## Run locally

1. Download and extract the ZIP archive.
2. Open `final vvce/pedestrain_system/index.html` in a modern browser.
3. Allow internet access for map tiles.
4. Set a start and destination on the map (or use the demo points).
5. Select **Start Simulation** to run the simulated crowd updates and automatic rerouting.
