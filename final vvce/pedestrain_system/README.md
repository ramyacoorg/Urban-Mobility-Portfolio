Pedestrian Roadmap & Guidance — Demo Package
Center: 12.978813, 77.5996565 (from provided Google Maps link)

This package is a client-side demo illustrating:
- Map layer integration (Leaflet + OSM) centered on M. Chinnaswamy Stadium.
- Simulated crowd clusters producing dynamic risk zones.
- Risk-weighted graph routing (Dijkstra) that finds the safest route.
- Alerts (voice + popup), drone warning simulation, and attractive UI.

Files:
- index.html
- style.css
- app.js
- data/exits.geojson

How to run:
1. Unzip the package.
2. Open index.html in a modern browser (internet required for tiles).
3. Click the map to set Start then Destination (or use 'Place Demo Points').
4. Click 'Start Simulation' to toggle live cluster updates and automatic rerouting.
